# تطبيق حضوري (Houdouri) — مسجل الحضور والانصراف الشخصي للأندرويد

تم رفع هذا المشروع تلقائياً مع إعداد البناء السحابي التلقائي (**GitHub Actions**).

## تحميل ملف الـ APK الجاهز للتثبيت
1. اضغط على تبويب **Actions** في أعلى هذا المستودع.
2. اختر أحدث عملية بناء (**Build Houdouri APK**).
3. من قسم **Artifacts** بالأسفل، حمّل ملف **Houdouri-Android-APK** الذي يحتوي على `app-debug.apk` وثبّته على هاتفك الأندرويد.
